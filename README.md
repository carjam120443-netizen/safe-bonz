# Safe Bonz 🦍

A simple, open-source desktop pet inspired by the classic desktop assistant era — without the unwanted stuff.

## Goals

- 🐵 Friendly desktop companion
- 💬 Harmless speech bubbles and messages
- 🖱️ Simple mouse interaction
- 🚶 Optional wandering and idle animations
- 🔇 Easy mute/pause controls
- 📦 Portable-friendly
- 🔒 No ads, tracking, telemetry, browser hijacking, or sketchy downloads
- 🌐 No network access unless a future feature explicitly needs it

## Project status

🚧 Early development. The repository currently contains the project foundation; the actual pet is coming next.

## Planned features

- Transparent desktop pet window
- Original mascot and animations
- Random idle messages
- Drag/click interaction
- Right-click menu
- Windows build
- Linux support
- Configurable personality/messages

## Safety philosophy

Safe Bonz should behave like a normal desktop application. It should not modify browser settings, collect personal information, install unwanted software, hide processes, or make changes outside what the user explicitly asks it to do.
